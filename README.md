# どのお小遣いが嬉しい？ ～増え方の数学～

高校生以上向けの数列・関数の探究アプリ。HTML / CSS / JavaScriptのみで動作し、外部ライブラリ・通信・ビルドは不要です。

## 起動・公開

`index.html` をブラウザーで開くか、このディレクトリを静的サーバーで配信してください。GitHub Pagesではブランチのルートを公開元に設定できます。

## 使い方

1. A・B・Cから予想を選んで実験を開始。
2. 「次の1か月へ」または自動再生で進め、受取額・累計額の順位、逆転、縮まった差を観察。
3. グラフを受取額／累計額、通常／対数で切り替え。表には現在までの月だけを表示。
4. 1か月以上体験したら自由実験を開き、各プランを独立に設定。
5. 必要に応じて一般項・累計の公式を開く。

実験は60か月まで。金額・増加額は0〜1兆円、倍率は0〜100。計算はJavaScriptの浮動小数点数で行い、表示のみ小数第2位まで丸めます。10¹⁵円以上は科学表記です。同額は同順位（例：1位・1位・3位）。逆転は各ペアの大小関係が反転した月に検出し、途中で同額になる月を挟んだ場合も検出します。順位の数字だけが変わっても、大小関係が反転していなければ逆転とは表示しません。

## テスト

Node.jsで実行（テストも追加ライブラリ不要）：

```sh
node tests/engine.test.js
```

金額・累計、独立した設定、同順位、同額を挟む逆転、毎月／累計の逆転月、縮まる差、戻る・リセット、未来の非表示、再生・停止・速度変更・上限停止を検証します。

`engine.js`：計算・実験の状態、`app.js`：UI・SVGグラフ、`style.css`：レスポンシブ表示。
